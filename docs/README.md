# docs

このプロジェクトで導入したツールや、その導入手順をまとめるディレクトリです。

新しいツールを導入した際は `docs/tools/` に1ファイル作成し、下記フォーマットに沿って記録してください。

## 記録フォーマット

各ファイルは以下の見出し構成を基本とします。

- 概要: 何のためのツールか、なぜ導入したか
- インストール手順: 実際に叩いたコマンド
- 設定・運用方針: ディレクトリ構成やGit管理方針など、プロジェクト固有の決定事項
- 参考リンク
